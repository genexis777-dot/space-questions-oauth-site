Space Questions

Daily Shorts publishing tool

This is a personal tool for preparing short, narrated astronomy videos from NASA Scientific Visualization Studio source material and uploading them to the owner’s YouTube channel.

The Google connection lets the tool confirm which channel is selected, inspect recent uploads to avoid duplicates, and upload a new video. It is used only by the channel owner. It does not provide a public sign-in service.

Videos use credited source imagery. Generated scripts are checked against source text before rendering, but the channel owner remains responsible for the published content.
