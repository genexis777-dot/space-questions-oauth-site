Privacy policy

Effective 16 October 2026

Who uses this tool

This is a personal publishing tool for the owner of @neoparadox99. It is not offered as a sign-in service to visitors.

Google data accessed

With the owner's consent, the tool reads the selected YouTube channel ID and recent upload metadata to verify the correct channel and avoid posting the same episode twice. It uploads new videos and their titles, descriptions, and privacy setting to that channel. It does not read unrelated Google services.

Storage and sharing

The Google OAuth refresh token is stored as an encrypted secret in the owner's private GitHub repository. A temporary access token is used during each run. The private repository records the NASA source ID and resulting YouTube video ID to prevent repeats. The tool does not sell Google user data or share it with advertisers. YouTube receives the uploaded video and metadata as part of the service requested by the owner.

Retention and control

The owner can stop future runs by disabling the schedule, remove the GitHub Actions secrets, delete the publishing record, and revoke the app's Google access at Google Account connections. Videos already uploaded remain subject to the owner's YouTube settings until the owner changes or removes them.

Contact

Questions can be sent through the contact address displayed on the Google consent screen.
